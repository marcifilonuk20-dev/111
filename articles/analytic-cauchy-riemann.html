解析函数与柯西-黎曼方程

2026年5月12日 复变函数

1. 复变函数的导数——一个苛刻得多的定义

复变函数 $f$ 在点 $z_0$ 处的导数定义为：

$$f'(z_0) = \lim_{z \to z_0} \frac{f(z) - f(z_0)}{z - z_0}$$

这个定义在形式上与实函数完全一致，但含义迥然不同：差商 $\frac{f(z) - f(z_0)}{z - z_0}$ 的极限必须沿复平面上所有可能的路径都收敛到同一个值。实函数只需考虑左右两侧，复函数则需要考虑无穷多种趋近方式。正是这一苛刻的要求使得可导的复变函数具有许多实可导函数所没有的刚性性质。

2. 柯西-黎曼方程（Cauchy–Riemann）

令 $f(z) = u(x, y) + i v(x, y)$，其中 $z = x + iy$。假设 $f$ 在 $z_0 = x_0 + i y_0$ 处可导。分别沿实轴方向（$z = x + iy_0$）和虚轴方向（$z = x_0 + iy$）计算差商极限：

沿实轴：$$f'(z_0) = u_x(x_0, y_0) + i v_x(x_0, y_0)$$
沿虚轴：$$f'(z_0) = v_y(x_0, y_0) - i u_y(x_0, y_0)$$

令两者相等，比较实部和虚部得到著名的柯西-黎曼方程：

$$\boxed{u_x = v_y, \quad u_y = -v_x}$$

C-R 方程是复变函数可导的必要条件。加上 $u, v$ 在 $(x_0, y_0)$ 处可微（作为二元实函数），C-R 方程也是充分条件。此时 $f'(z_0) = u_x + i v_x = v_y - i u_y$。

3. 验证经典例子

$f(z) = z^2$：$u = x^2 - y^2$，$v = 2xy$。计算偏导数：$u_x = 2x$，$u_y = -2y$，$v_x = 2y$，$v_y = 2x$。C-R 方程成立（$u_x = v_y$，$u_y = -v_x$），故 $f$ 在全平面可导，且 $f'(z) = 2x + i2y = 2z$。

$f(z) = \overline{z}$：$u = x$，$v = -y$。$u_x = 1$，$v_y = -1$。C-R 方程 $u_x = v_y$ 不成立（$1 \neq -1$），故 $\overline{z}$ 处处不可导，尽管其实部和虚部都是非常"好"的函数。

这个对比极其重要：$\overline{z}$ 作为 $\mathbb{R}^2 \to \mathbb{R}^2$ 的映射是光滑的（线性映射 $(x, y) \mapsto (x, -y)$），但它不是复可导的。由此可见，复可导性是附加在二元实函数之上的一个高度非平凡的代数约束。

4. 解析函数与全纯函数

$f$ 在 $z_0$ 处解析（analytic）或称全纯（holomorphic），如果 $f$ 在 $z_0$ 的某个邻域内处处可导。$f$ 在区域 $D$ 上解析，如果它在 $D$ 内的每一点都解析。

注意：在一点可导不一定在该点解析。例如 $f(z) = |z|^2 = z \overline{z}$ 只在 $z = 0$ 处可导（$f'(0) = 0$），但在 $z = 0$ 的任何邻域内都不可导，因此它在 $0$ 处不可解析。

解析函数具有一系列令人惊叹的性质，这些性质在实函数世界中完全没有对应物：如果 $f$ 在一个区域上解析，那么它在区域内无穷次可导，它可以局部展开为幂级数，而且全由其在边界上的值所决定（柯西积分公式）。

5. 调和函数与解析函数的实虚部

如果 $f = u + iv$ 解析，且 $u, v$ 有连续的二阶偏导数（这可由解析性推出），则对 C-R 方程 $u_x = v_y$ 关于 $x$ 求偏导、$u_y = -v_x$ 关于 $y$ 求偏导后相加：

$$u_{xx} + u_{yy} = v_{yx} - v_{xy} = 0$$

即 $u$ 满足拉普拉斯方程 $\Delta u = 0$。同样 $\Delta v = 0$。满足拉普拉斯方程的函数称为调和函数。

因此：解析函数的实部和虚部都是调和函数。反过来，给定一个调和函数 $u$，我们可以找到其共轭调和函数 $v$（通过解 C-R 方程确定到相差一个常数），使得 $f = u + iv$ 解析。

这一联系使复分析成为求解二维拉普拉斯方程（出现在热传导、静电学、流体力学等众多物理问题中）的强大工具——解析函数提供了一个取之不尽用之不竭的调和函数来源。

6. C-R 方程的极坐标形式

当使用极坐标 $z = re^{i\theta}$ 时，C-R 方程有等价的极坐标形式。令 $u(r, \theta), v(r, \theta)$，可导条件为：

$$u_r = \frac{1}{r} v_\theta, \quad v_r = -\frac{1}{r} u_\theta$$

这两种形式在不同场景下各有便利之处。例如，验证 $f(z) = \log z$（对数函数）的解析性时，极坐标形式更为自然。

小结

柯西-黎曼方程是复分析的第一道门槛。它们将"复可导"这一抽象要求转化为一对简洁的偏微分方程，从而搭建了复分析与实分析、偏微分方程之间的桥梁。在下一篇中，我们将看到 C-R 方程如何与复积分结合，产生柯西积分定理这一复分析中最深刻的结果。
