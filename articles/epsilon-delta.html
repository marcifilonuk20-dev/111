深入理解 ε-δ 语言

2026年2月20日 数学分析

1. 直觉的极限与严格的极限

初学微积分时，我们常说"$\lim_{x \to a} f(x) = L$ 意味着当 $x$ 越来越接近 $a$ 时，$f(x)$ 越来越接近 $L$"。这种描述提供了直觉，但有两个致命的模糊之处：什么是"越来越接近"？"接近"到什么程度才算？在严格的数学中，"越来越"这个时间性的词汇必须被替换为精确的量化关系——这就是 ε-δ 语言的根本动机。

ε-δ 定义将"动态的趋近过程"转化为静态的逻辑条件。一旦理解了这一转换，整个分析的严格性大厦都建立在这块基石之上：连续性、可导性、可积性、一致连续性——它们的定义全都是 ε-δ 模式的变体。

2. 函数极限的 ε-δ 定义

$\displaystyle\lim_{x \to a} f(x) = L$ 当且仅当：
$\forall \varepsilon > 0,\ \exists \delta > 0$，使得 $0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon$。

这个定义中的每个符号都有精确的含义：

$\varepsilon$（epsilon）是"误差容限"——你允许 $f(x)$ 偏离 $L$ 的最大距离。它可以是任意正数，无论多少。
$\delta$（delta）是"靠近程度"——我需要的 $x$ 与 $a$ 之间的距离上限，以保证输出误差在 $\varepsilon$ 之内。
全称量词 $\forall$ 在先、存在量词 $\exists$ 在后——这个顺序至关重要：针对你给出的任意 $\varepsilon$，我能找到一个 $\delta$（它通常依赖于 $\varepsilon$）。

注意条件中的 $0 < |x - a|$：$x = a$ 本身被排除在外。函数在 $a$ 处的极限与 $f(a)$ 的值（甚至是否有定义）完全无关。极限描述的是 $f$ 在 $a$ 的去心邻域内的行为。

3. 第一个严格证明：线性函数

证明 $\lim_{x \to 2} (3x + 1) = 7$。

分析阶段（草稿）：我们需要 $|(3x + 1) - 7| < \varepsilon$。化简：$|3x - 6| = 3|x - 2| < \varepsilon$，即 $|x - 2| < \varepsilon/3$。因此取 $\delta = \varepsilon/3$ 应该可行。

正式证明：任给 $\varepsilon > 0$，取 $\delta = \varepsilon/3$。若 $0 < |x - 2| < \delta$，则

$$|(3x + 1) - 7| = |3x - 6| = 3|x - 2| < 3 \cdot \frac{\varepsilon}{3} = \varepsilon$$

故 $\lim_{x \to 2} (3x + 1) = 7$。注意证明的结构：先声明 $\delta$ 的取值，再验证当 $|x - a| < \delta$ 时 $|f(x) - L| < \varepsilon$ 成立。

4. 二次函数的极限——$\delta$ 依赖于 $\varepsilon$ 的典型例子

证明 $\lim_{x \to 1} x^2 = 1$。

分析：$|x^2 - 1| = |x - 1| \cdot |x + 1|$。如果 $x$ 靠近 $1$，则 $|x + 1|$ 大致在 $2$ 附近。设 $|x - 1| < 1$，则 $0 < x < 2$，从而 $1 < x + 1 < 3$，即 $|x + 1| < 3$。于是 $|x^2 - 1| < 3|x - 1|$。令 $3|x - 1| < \varepsilon$，即 $|x - 1| < \varepsilon/3$。取 $\delta = \min\{1, \varepsilon/3\}$。

正式证明：任给 $\varepsilon > 0$，取 $\delta = \min\{1, \varepsilon/3\}$。若 $0 < |x - 1| < \delta$，则 $|x - 1| < 1$ 推出 $|x + 1| < 3$，且 $|x - 1| < \varepsilon/3$。故

$$|x^2 - 1| = |x - 1| \cdot |x + 1| < \frac{\varepsilon}{3} \cdot 3 = \varepsilon$$

这里的技术要点：先对 $|x - a|$ 施加一个粗约束（如 $< 1$）来控制额外的因子，再用 $\varepsilon$ 精细调整。$\delta = \min\{1, \varepsilon/3\}$ 是这种"双重约束"的标准写法。

5. 单侧极限

有时我们只关心从一侧趋近的行为。右极限 $\lim_{x \to a^+} f(x) = L$ 的定义只需将 $\varepsilon$-$\delta$ 中的 $0 < |x - a| < \delta$ 替换为 $0 < x - a < \delta$（即 $a < x < a + \delta$）。左极限的定义则替换为 $-\delta < x - a < 0$（即 $a - \delta < x < a$）。

极限存在的充要条件是左右极限都存在且相等。例如 $f(x) = |x|/x$ 在 $x \to 0$ 时右极限为 $1$，左极限为 $-1$，故极限不存在。

6. 无穷极限与无穷远处的极限

ε-δ 框架自然地扩展来处理发散到无穷和变量趋于无穷的情况。

$\lim_{x \to a} f(x) = \infty$：$\forall M > 0,\ \exists \delta > 0$，使得 $0 < |x - a| < \delta \implies f(x) > M$。这里 $M$ 取代了 $\varepsilon$，表示"任意大的数"。

$\lim_{x \to \infty} f(x) = L$：$\forall \varepsilon > 0,\ \exists X > 0$，使得 $x > X \implies |f(x) - L| < \varepsilon$。这里 $X$ 取代了 $\delta$，表示"足够大的数"。

$\lim_{x \to \infty} f(x) = \infty$：$\forall M > 0,\ \exists X > 0$，使得 $x > X \implies f(x) > M$。所有四种组合都可以在统一的量化框架中处理，这种统一性是 ε-δ 语言优雅性的体现。

7. 连续性的 ε-δ 表述

$f$ 在 $a$ 处连续的定义只需在极限定义中去掉 $0 < |x - a|$ 的限制（允许 $x = a$）：$\forall \varepsilon > 0,\ \exists \delta > 0$，使得 $|x - a| < \delta \implies |f(x) - f(a)| < \varepsilon$。这等价于 $\lim_{x \to a} f(x) = f(a)$。

连续函数类对四则运算封闭（只要分母不为零），对复合运算也封闭——这些都可以用 ε-δ 语言直接证明。介值定理和极值定理的证明虽然需要实数完备性（确界原理），但证明过程的核心操作仍然是 ε-δ 构造。

8. 一致连续性——$\delta$ 不依赖于点

普通连续性中，$\delta$ 可以同时依赖于 $\varepsilon$ 和点 $a$。$f$ 在集合 $E$ 上一致连续，如果 $\forall \varepsilon > 0,\ \exists \delta > 0$（这个 $\delta$ 只依赖于 $\varepsilon$，而不依赖于 $E$ 中的具体点），使得对任意 $x, y \in E$，$|x - y| < \delta \implies |f(x) - f(y)| < \varepsilon$。

$f(x) = x^2$ 在 $\mathbb{R}$ 上连续但不一致连续：对给定的 $\varepsilon$，随着 $x$ 的增大，需要越来越小的 $\delta$ 来控制 $|x^2 - y^2| = |x - y| \cdot |x + y|$（因为 $|x + y|$ 可以任意大）。但在任何紧区间（如 $[0, 1]$）上，$x^2$ 一致连续——紧集上的连续函数必一致连续（Heine–Cantor 定理）。

9. 数列极限与函数极限的关系

$\lim_{x \to a} f(x) = L$ 成立当且仅当：对于任意满足 $\lim_{n \to \infty} x_n = a$（且 $x_n \neq a$）的数列 $\{x_n\}$，都有 $\lim_{n \to \infty} f(x_n) = L$。这个海涅定理（Heine's theorem）将函数极限归约为数列极限，是许多存在性证明（包括证明极限不存在——找到两条不同的逼近路径给出不同的极限值）的核心技术。

10. ε-δ 语言在分析学中的核心地位

ε-δ 语言不仅仅是微积分课本中的一个技术细节。它是数学从 17-18 世纪的直觉推理（牛顿、莱布尼茨、欧拉）走向 19 世纪严格化（柯西、魏尔斯特拉斯）的标志。魏尔斯特拉斯在 1861 年左右首次给出了现在使用的 ε-δ 定义形式，终结了长期以来关于"无穷小量"的哲学争论。

掌握了 ε-δ 语言，你就掌握了打开数学分析所有后续章节的钥匙：导数 (ε-δ)、定积分 (ε-δ)、函数项级数的一致收敛 (ε-N 变体)、Lebesgue 测度 (ε-δ 的集合版本)……全都是同一个逻辑模式的变奏。
