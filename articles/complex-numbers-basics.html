复数的基本概念与几何表示

2026年5月10日 复变函数

1. 从解方程到虚数单位

在实数范围内，方程 $x^2 + 1 = 0$ 无解。为了弥补这一缺陷，我们引入虚数单位 $i$，满足 $i^2 = -1$。由此，任意复数可以表示为 $z = x + yi$，其中 $x, y \in \mathbb{R}$，$x$ 称为实部 $\operatorname{Re}(z)$，$y$ 称为虚部 $\operatorname{Im}(z)$。

复数的引入并非纯粹的理论游戏——它在数学物理、电路分析、流体力学和量子力学中都是不可或缺的工具，因为复数天然地编码了"大小"和"方向"（或说"相位"）两个维度的信息。

2. 复数的四则运算

复数的加法和乘法将实数运算自然推广。设 $z_1 = x_1 + y_1 i$，$z_2 = x_2 + y_2 i$：

加法：实部加实部，虚部加虚部——

$$z_1 + z_2 = (x_1 + x_2) + (y_1 + y_2)i$$

乘法：按分配律展开，利用 $i^2 = -1$ 合并——

$$z_1 z_2 = (x_1 x_2 - y_1 y_2) + (x_1 y_2 + y_1 x_2)i$$

除法：分子分母同乘分母的共轭——

$$\frac{z_1}{z_2} = \frac{x_1 + y_1 i}{x_2 + y_2 i} = \frac{(x_1 + y_1 i)(x_2 - y_2 i)}{x_2^2 + y_2^2}$$

3. 复平面：复数的几何直观

这是理解复变函数最重要的视角。将复数 $z = x + yi$ 与平面上的点 $(x, y)$ 一一对应，这个平面称为复平面（或 Gauss 平面）。横轴为实轴，纵轴为虚轴。

在此视角下，复数加法就是平面向量的加法（平行四边形法则）。复数乘法则更微妙——它同时涉及伸缩和旋转，这正是复变函数许多优美性质的几何根源。

定义复数的模：$|z| = \sqrt{x^2 + y^2}$，即点到原点的距离。

定义共轭复数：$\overline{z} = x - yi$，即关于实轴的对称点。共轭满足 $\overline{z_1 + z_2} = \overline{z_1} + \overline{z_2}$ 和 $\overline{z_1 z_2} = \overline{z_1} \cdot \overline{z_2}$。

4. 极坐标形式与辐角

将复数用极坐标表示，其几何意义更加清晰。设 $z = x + yi \neq 0$，令 $r = |z|$，$\theta$ 为从正实轴逆时针旋转到 $z$ 的角度（称为辐角，记作 $\arg z$），则：

$$z = r(\cos\theta + i\sin\theta) = r e^{i\theta}$$

其中 $e^{i\theta} = \cos\theta + i\sin\theta$ 是著名的欧拉公式。它给出了指数函数与三角函数在复数域中的深刻联系。

注意辐角的多值性：$\arg z$ 可以相差 $2\pi$ 的整数倍。通常取 $(-\pi, \pi]$ 中的值作为主辐角 $\operatorname{Arg} z$。

5. 极坐标下的乘除法——几何意义的揭示

极坐标形式让复数的乘法与除法的几何意义一目了然：

$$z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}$$ $$\frac{z_1}{z_2} = \frac{r_1}{r_2} e^{i(\theta_1 - \theta_2)} \quad (z_2 \neq 0)$$

模相乘（除），辐角相加（减）。这就是复数乘法的几何解释：模长缩放到乘积，辐角旋转到和。复变函数的许多关键性质——譬如解析函数的保角性——都发源于这一简单事实。

6. 棣莫弗公式与复数的 $n$ 次根

由欧拉公式直接得到棣莫弗公式（de Moivre）： $$(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)$$

这个公式给出了求复数 $n$ 次根的钥匙。方程 $w^n = z$ 在复数域中恰好有 $n$ 个解： $$w_k = \sqrt[n]{r} \exp\left(i\frac{\theta + 2k\pi}{n}\right), \quad k = 0, 1, \dots, n-1$$

这 $n$ 个根均匀分布在复平面上以原点为中心、半径为 $\sqrt[n]{r}$ 的圆上。例如，$1$ 的三次方根（即 $z^3 = 1$ 的解）是： $$1, \quad e^{2\pi i/3}, \quad e^{4\pi i/3}$$ 它们构成正三角形的三个顶点——这就是复数的几何之美。

7. 复数的拓扑基础

在后续讨论复变函数的极限与连续性之前，需要建立复平面上的一些基本拓扑概念。

点 $z_0$ 的$\varepsilon$-邻域是以 $z_0$ 为圆心、$\varepsilon$ 为半径的开圆盘：$D(z_0, \varepsilon) = \{ z \in \mathbb{C} \mid |z - z_0| < \varepsilon \}$。

一个集合 $D \subset \mathbb{C}$ 是开集，如果其中的每一点都存在一个完全包含于 $D$ 的 $\varepsilon$-邻域。一个集合是连通的，如果其中的任意两点都可以用一条完全位于该集合内的折线相连。既是开集又是连通集的集合称为区域——这是复变函数论中最基本的定义域。

小结

复数不只是实数的简单扩充。复平面的几何结构——特别是乘法对应于旋转与伸缩——赋予了复变函数一系列实数函数不具备的优美性质。在后续文章中，我们将看到这些几何直觉如何转化为严格的解析理论。
